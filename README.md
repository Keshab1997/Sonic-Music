- 🎶 Browse & play your music

- 📱 Responsive on all screens
- ⚡ Smooth, snappy playback

## 🛠️ Built With

- **TypeScript — core language**
- **Modern web stack**
- **Vercel — easy deployment**

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Keshab1997/Sonic-Music.git
# Install dependencies
npm install
# Start the app
npm run dev
```
